# ROMarrNG for YunoHost

This repository contains the YunoHost package for ROMarrNG. The canonical
package files are maintained in the ROMarrNG source repository under
packaging/yunohost and mirrored here.

The main branch is the reviewed package version. The testing branch follows
the source repository's committed package metadata and is used for catalog
review and early installs.

To install the testing package:

    sudo yunohost app install https://github.com/YunoHost-Apps/romarrng_ynh/tree/testing

For installation and administration details, see doc/ADMIN.md and
doc/POST_INSTALL.md.
